# V1结构装配与人工确认

这是800 mm长、以3 mm木板为概念材料的结构评审模型。可查看外形、板件连续性、插接方向和内部空腔；尚未实际切板或拼装，不能作为最终下料包。

## 坐标与分层

X=0船艏，X=800船艉；Y=0中心线，+Y右舷，-Y左舷；Z从模型基线向上。Z=0不是设计水线。本版没有确定实际吃水。

用户指定的01–11层全部保留，另外12为可拆飞行甲板、13为模型内部甲板、14为弹射与阻拦预留、15为定位标记、98为隐藏的板件平面轮廓。彩色RESERVED_VOLUME表示必须留空的包络，不参与木料统计，不能把它们做成实心块。

## 骨架与插接原理

中央龙骨K01是一片纵向3 mm板，X=0–800连续。机库下方保持低龙骨，艉部下降至Z=15，位于坞舱地板下面，避免用高龙骨把机库和坞舱切成左右两半。细长艉段和艏端局部强度仍需实物评审。

24片模型肋骨F01–F24站位为18、35、53、74、98、126、158、194、232、270、308、346、384、422、460、498、536、574、612、650、688、726、760、788 mm。它们代表模型制造骨架，不是原舰肋位。

龙骨在每片肋骨处开向上的半深槽；肋骨在中心线处开向下的半深槽。装配时把肋骨从上方落入龙骨槽，两片板在共同中间高度交错连接。槽宽取目标成品宽度3.12 mm，形成总宽余量0.12 mm，即居中时每侧约0.06 mm。少量胶水在干拼确认后加固接缝。

左右主纵梁位于Y=±49、X=135–792、Z=24–40。每条穿过18片肋骨。纵梁开向下的半深槽，肋骨对应位置开向上的槽，共同交接高度Z=32。纵梁从上方落入肋骨，连接多个肋位。左右舷Z=75的局部甲板托条进一步支持甲板边缘；升降机处断开，避免跨过升降机开口。所有板件均为单连通板件，已检查不存在切口造成的孤立碎片。

3 mm仍是名义厚度。木板实际厚度、翘曲、木纹方向、烧蚀和窄桥断裂会影响装配。插槽交会、4 mm左右窄桥、艏部小肋骨以及艉部低龙骨是实物重点检查项。本版没有宣称已验证承载能力。

## 推荐干拼顺序

1. 测量同批木板厚度，在拟采用设备上切FIT_TEST测试板，选出能手压装入且不会撑裂的目标槽宽。切割缝和配合余量可调整后重建。当前内部标高仅协调名义3 mm板厚；生成器会拒绝把MATERIAL_THICKNESS改为其他值。实际板厚不同，需要先重设计地板、托条和预留标高并重新做干涉检查，不能仅改厚度就下料。
2. **先穿装机库地板与相关肋骨。** 570×86 mm整片机库地板会被肋骨上横梁捕获，不能在骨架装完后从上面放入或抬出。先让F08–F22从地板艉端依次穿入，先穿最靠艏的F08，再按顺序穿F09至F22；用可拆定位夹具保持各自X站位和地板Z=41。各肋骨的地板通道左右各让0.15 mm。此时不要点胶。
3. 把K01放到平直装配底板上，校准中心线与基线。把上述地板/肋骨组件作为一组落入龙骨对应槽，再装艏部F01–F07和艉部F23–F24。用夹具和角尺控制垂直、站位和扭曲，不能靠地板摩擦自行定位。
4. 从上方插入左右主纵梁。Y=±49的纵梁位于Y=±43地板之外，不必穿过整片地板。从敞开的艉口沿X方向滑入坞舱地板，其通过肋骨的开口左右各让0.15 mm。再装检修盖下方托条和局部上部甲板托条；托条Z=38–41、盖板Z=41–44。全部干拼确认后才点胶。上述为根据几何审查后的概念装配顺序，尚未经过实体干拼验证。
5. 放入电池、电控和电机的等体积纸样或空盒，检查维修盖能拿出设备、接头可接近、导线可穿过。暂不安装真实轴系和螺旋桨。
6. 试放四块飞行甲板。甲板缝位于X=194、422、650附近，总缝宽0.3 mm。面板独立可抬起，不能永久粘合到船体。防滑定位/夹扣方式尚待选择，不应依靠本版示意当成成熟锁扣。机库主地板为装配时穿入、后续被骨架捕获的板件，日常维护只通过四个可取出的检修盖进行。
7. 舰岛分别随各自甲板面板拆下；两处升降机保持舷侧开口。下降平台只画了3 mm板，不含升降机构，不能据此加工导轨或传动装置。
8. 最后讨论蒙皮分片与固定方式。灰色外形面没有板厚，不能当作一体船壳。3 mm平木板难以贴合艏部复曲面，需人工决定分条/分片与接缝，重新验算外形和装配余量。

## 切割缝与配合

`MATERIAL_THICKNESS = 3.0 mm`，`CUTTING_KERF = 0.15 mm`（假设值），`FIT_CLEARANCE = 0.12 mm`（成品槽的总余量）。

`SLOT_WIDTH = MATERIAL_THICKNESS + FIT_CLEARANCE = 3.12 mm`，这是三维板件表示的目标成品槽宽。

- 使用CAM内外轮廓刀补时：提供3.12 mm成品槽轮廓，由CAM施加刀补。
- 激光中心线照路径切、没有CAM刀补时：槽路径间距为3.12−0.15=2.97 mm，切后两侧各烧去约半个切割缝，使开口增宽至约3.12 mm。FIT_TEST_NO_CAM_COMPENSATION的整个外轮廓已向木料外侧偏置K/2；不要再次加同样刀补。
- CNC铣削必须按实际刀径、CAM规则处理内角与必要的清根/狗骨，不能套用激光切割缝公式。V1没有生成CNC狗骨，也没有发布CNC可切板件。

FIT_TEST提供目标成品槽宽2.85–3.30 mm的11档和同材质插片。两个DXF版本分别对应CAM负责补偿和无CAM补偿。文字属于刻字/标记内容，不能当作贯穿切线。SVG为1:1尺寸检查图，打印须100%且关闭适合页面。

## 内部空间与可维护性

机库主要净空位于X=180–750、Y约±43、Z=44–74；左前部降低到Z=64，艉部中央降低到Z=65，避让弹射及阻拦机构预留。它不是外形规则的单一长方体，仍保持整体连通。坞舱净空X=610–800、Y=±27、Z=18–38，并通向艉部开口。

电池预留110×34×26 mm，电控115×34×26 mm。两处对称动力空白区各90×37×29 mm，未来可依据实际机构合并或改动。所有大小都是模型功能设计，并未按实际选定设备包络验证。机库地板维修盖分别通向这些区域。走线条带和艉部服务通道贯穿对应肋骨；装设备前仍需验证线束弯曲半径、接头与防水。

甲板只保留一条左前弹射轨迹和艉部着舰区域边界，没有把示意线当作真实阻拦索数目、位置或机械构造。

## 文件与验证边界

3dm板件为独立、封闭的三角网格，另带隐藏的精确平面轮廓；可在Rhino选取/移动、分层查看。它们不是布尔合并的一体实体，参数修改通过源代码与JSON重建。需要NURBS实体时，可按所附平面轮廓在Rhino挤出，V1没有假称网格就是NURBS。

已执行文件保存回读、板件连通/闭合、800 mm包围盒、插槽/预留几何和本地浏览器预览验证。具体结果见`tables`中的检查文件。Rhino桌面原生打开、真实木板干拼、装配承载和最终切割工艺均不能由这些数值检查替代。
