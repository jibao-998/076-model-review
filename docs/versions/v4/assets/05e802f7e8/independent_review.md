# V4 船体优化与基础附体独立审查

复核日期：2026-10-17。复核对象为最终默认布局：锚孔X52/Z53，轴起点[722, ±28, 18]，桨中心X758/Y±28/Z4.5，舵叶X767–777，舵轴X769、半径1、Z16–25。除本记录外，复核未修改产品源码、参数或模型。

结论：先后发现的锚孔内壁侵入首肋、传动轴侵入下横板、舵轴侵入末肋问题，均已在当前文件中解除。当前未发现阻止造型与静态结构评审的遗留几何问题。此结论不表示已完成真实系统恢复、制造、装配运动或下水验证。

## 独立几何证据

| 检查项 | 本轮结果 |
|---|---|
| 母面正则性 | 独立重建当前参数母面，采用规则与近边界加密采样。前、后体内部Jacobian模长均为有限正数，采样中最小值约1.29×10⁻⁵和1.70×10⁴；du的X分量为正，dv的Z分量未见超出数值误差的负值。这是局部正则与方向采样，不能替代完整原生自交检查。精确退化参数角点不计入内部正则性结论。 |
| 前后体接口 | 在X160共同参数接口独立检查位置、一阶及全部二阶偏导。位置最大差约5.68×10⁻¹⁴ mm，二阶参数导数最大差约1.32×10⁻⁹。该证据针对这一接口，不是全船所有接缝的G2认证。 |
| 镜像中心线 | 前体底接缝加密采样的左右外法向差不超过约1.35×10⁻⁸°；后体底接缝为0°；水下艏柱1001点检查为0°。上部窄艏柱、横艉、锚孔口缘和附体连接不能由此自动升级为同等级光顺连接。 |

| 运行机构与结构互查 | 另外提取11个运行机构封闭显示实体，与上述58实体交叉筛查；8对候选布尔均无正体积交叠。与上项合计79对。螺旋桨叶、支架等零厚度参考面及机构内部预期连接不计入这项零交叠声明。管件显示网格为圆周离散近似，不能称为原生圆柱曲面的精确布尔。 |

## 原生文件、保护与资料边界

- 回读装配/骨架/爆炸文件，分别为208/31/208个有效原生对象，单位mm，均零Mesh。装配文件全部对象的原生X包围盒为0–800 mm；爆炸文件X范围为−41–841.2 mm，属于展示位移，不是装配总长。
- 对三个文件共15个命名视图，独立将可见原生对象保守包围盒角点投影至保存相机，检查XY及近远裁剪，全部通过。各文件最差归一化XY投影范围约为装配0.869290、骨架0.863905、爆炸0.892575。
- 对V3中飞行甲板、上层建筑、标线、升降机平台和甲板托条组的42个对象，逐项比较原生 `Geometry.Encode()`，全部相等。母面、肋骨和横板本版允许更新，不能再声称船体母面与V3不变。
- `input_hashes.json`登记的五个V3原文件SHA独立核对相符，原版受到保护。
- 九张参考图片的SHA均与登记相符；共有八个唯一图，R02与R01重复。资料登记将其列为用户提供的CGI/模型图片，水印作者和原始链接未核实。它们只能支持D级造型选择，不能成为真实076水下型线、双轴双桨双舵数量或附体尺寸的确认依据。

## 验证边界

本轮使用普通Python、rhino3dm原生文件回读、NURBS数学导数、二维轮廓和显示网格布尔。**没有操作原生Rhino桌面**；原生Zebra、CurvatureGraph、Join/裸边/法向、水密及完整自交检查均为NOT_CHECKED。

本轮未另建目录重做整包解压构建，也未独立重跑最终网页交互；相应结果应查看交付的单独验证记录。源码使用包内相对输入与内嵌网页依赖；Python重建需要预先安装requirements中的包。

结构内部、球鼻、舭龙骨、推进系统示意、锚孔和过道的具体坐标与尺寸继续按D模型设计处理；继承的少量外部尺度估算仍需保留其C来源边界。真实076轴、桨、舵及水下附体配置保持Unknown。

蒙皮与舭龙骨等仍含零厚度参考面；1.25 mm肋骨内缩尚未与3 mm实物蒙皮协调。未验证真实双横板穿装、木纹/切割/承载、轴舵安装、最短法向净空、浮力、防水和实际运行。当前结果只支持进一步造型与静态装配评审。
