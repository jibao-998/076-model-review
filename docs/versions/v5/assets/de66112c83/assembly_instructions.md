# V5观察与拆装说明

这是模型设计D，不是076真实舱室。原生装配文件保持800mm，不能把爆炸后的包围盒作为装配总长。

## 使用交互预览

打开076_V5_功能与内部观察.html。螺旋桨区支持启动、暂停、0–600RPM数值输入（滑条0–240）；这是演示转速。桨叶、轮毂和轴沿原生轴线转动，轴管不转。

从列表搜索或点击模型选择单件，输入相对装配位置的ΔX/ΔY/ΔZ，应用位移。隐藏的部件仍可从列表选择并显示。复位单件只恢复该件；恢复全部部件恢复初始位置、可见性和暂停角度。展示移动不修改下载的原生装配文件。

“打开坞舱顶板”隐藏外板、飞行甲板及需先拆的横撑，并抬高顶板以观察；“打开机库顶板”隐藏上方甲板并抬高机库顶板。它们是观察快捷方式，不是完整安装动画。

## 已检查的候选检修路径

先卸除相应飞行甲板模块和附在甲板上的部件，解除锁止，再取出坞舱四根可拆横撑。横撑落在肋骨台阶上；X710左端另有立在上横板上的承托。抗拔锁止件尚未选定。

坞舱顶板和机库顶板可沿+Z提升130mm。按当前木质实体做了连续扫掠检查；未计入未来厚化蒙皮、真实线束、密封、紧固件、手部或工具。

坞舱左右侧板在顶板取出后，先向中心线平移3.06mm，再向艉平移170mm，经艉门取出。边界路径做了抽样木板碰撞检查，不能解读为制造公差已经合格。

坞舱平底内衬在前壁、侧壁和顶板取出后，先抬高16mm，再绕纵轴倾转35度，随后向上取出。此路径仅为当前参考实体的抽样候选；实际船壳厚度、检修口、握持和密封安装仍需另验。

完整龙骨、全部肋骨、纵梁及长横板的穿装顺序仍未验证；不要据局部检修路径直接下单切割整套木板。

## 实际装配/下水入口

下横板仍为Z19–22，新增独立平底内衬为Z22–25，因此坞舱净空变成X610–776、Y±22、Z25–44（长166、宽44、高19）。上横板/坞舱顶板仍Z44–47。新板件均按3mm；实际切割前须用材料试片确认配合。

现有1.25mm肋骨内缩与3mm蒙皮尚未协调。艉门下沿Z25；若未来实际水面高于该高度，坞舱可进水，必须将该工况和舱壁密封纳入评估。Z32只是显示参考高度，不能据此判断实际浮态。

硬件未选型。现有轴线向艏延伸将穿过横板，电机预留与轴系尚未连通，不能认为推进系统已经装配完成。先填hardware_inputs.csv，再规划轴管穿板、座架和密封；之后才能完成重量/浮态和物理试装、运行检验。
