## 本次改变与几何依据

- 两侧升降导向改为可检修侧袋；导杆、滑座、连接臂和固定承力框为D模型设计。侧袋局部延伸至|Y|64，未声称完全藏入原有母型内部。
- 双层倒角门框和带顶/侧壁的短通道；入口不用蒙皮封住。右舷接主机库，左舷接坞舱上方独立可拆局部场景。内景顶梁与灯具可拆，无真实076内部结构还原的主张。
- 平台改为**52×29mm候选**，V9的52×43mm只作历史比较。32mm行程暂定；上位顶Z79与甲板齐平，下位顶Z47与阈板齐平。两侧甲板边缺口随之回填至|Y|63.5，平台内侧边|Y|64，实际保存几何间隙0.5mm。
- 通道的验证核心为X向扣除倒角后的区域、Z47..66；不能把名义门框Z47..68解释为全宽21mm净高，局部顶板底Z67限制了实际净高。
- 固定升降框在整甲板移除时仍通过实际共面接触面连接邻近肋骨与纵向构件。此项只证明几何连接，不证明榫槽、紧固或承载能力。
- 左右锚孔旧凹坑背盖打开；各侧加入卷筒、轴、支承、可拆托盘及绳路中心线。锚体是简化D模型占件。卷筒位于X约117..132，电机体预留132..158；整托盘在110/160肋骨之间，避免上提时被肋骨顶拦住。
- 电池和电控各有3mm托盘、侧边围板及四点支承；通过与既有纵梁的实际面接触提供几何支承。名义设备空间各84×34×17mm，硬件未选型；连接器另留侧向空间。

## 拆装顺序与前置条件

1. 切断机构电源，确认平台有独立机械支承；解除尚未选型的甲板固定件。双手托板，连双岛沿+Z取下190mm；不得抓舰岛。
2. 断开照明插头并移线，取主机库顶板及左舷局部场景顶板；检查路径100mm。
3. 先拆导轨顶盖，再取开槽侧袋衬板；各90mm。实际固定件与工具规格未冻结。
4. 驱动断开、平台支承妥当后才可提出滑座/平台组件；上提路径100mm，不能把网页直接移动当作实物可安全操作。
5. 断开场景线束，取主机库组件和左舷局部内景，各100mm。
6. 解除设备/锚机托盘固定件，断开并移开线与绳，分别上提托盘100mm；检修后逆序定位、复接、检查限位。模型未包含已选定的快拆固定件。

## 候选硬件核查与停止点

厂商PQ12/L12不能完整竖置于Z47..76的29mm夹层。Haydon Ø15×11.2只是电机本体，不能代表整套丝杆装置；现有5×5×36mm执行器预留不能容纳这些已核查候选，**驱动安装仍是未解决项**，不得作为已适配安装座。

锚机26mm本体+10mm前轴区仅为候选尺寸比较，未确认减速比、联轴、安装支架、卷绕及牵引力。实际绳眼、导向滑轮、行程限位、卡滞检测、制动/防溜与手动释放必须后续完成。简化锚板与绳路端点只作几何对接，不代表选定实物连接。

本轮没有制作实物试件，没有固件、手机硬件控制、真实电量遥测或一小时续航结果。网页只模拟状态；真实遥测须来自传感器。原有推进/操舵硬件接口、整体蒙皮余量、水密、浮态与航行均不在本轮验收内。Rhino桌面打开和人工操作为**NOT_CHECKED**。

下一步先做右舷局部样段，冻结平台与驱动全包络，称量全部移动件，再进行承力、摩擦、防坠、限位及反复升降。锚机另做卷绕/卡滞试件。实物验证通过后才有制造图放行依据。
