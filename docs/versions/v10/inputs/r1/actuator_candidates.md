## 锚机：尺寸接口可研究，整套能力未知

[Pololu999厂商页](https://www.pololu.com/product/999/specs)与[厂商尺寸图PDF第4页](https://www.pololu.com/file/0J949/micro-metal-gearmotors-dimensions.pdf)重新核对：HP6V贵金属电刷、无编码器款截面10×12，图中本体OL最大25.6 mm，前输出D轴Ø3、轴长9 mm，前安装2×M1.6、孔距9 mm。本页表格本体25 mm、脚注26 mm且前轴区另加10 mm存在不一致；仅研究占位可保守使用26 mm本体＋10 mm前轴区，并明确尚未包括线端、支架与工具。

可比较的轴到卷筒接口为[Pololu1996厂商页](https://www.pololu.com/product/1996/specs)及[尺寸图](https://www.pololu.com/file/0J661/1996-3mm-m3-hub-dimensions.pdf)：Ø17.5×5 mm、Ø3孔、4×M3固定孔和M3顶丝，单件不含顶丝2.8 g。它是轴安装轮毂，不是卷筒，也不是完整轴对轴联轴器。卷筒、挡边、支承和导绳件仍为未知参数。

999在6V下空载约3100 rpm，不能据此视作已适合慢速收锚的减速比。应按实际绳张力与有效卷绕半径核算轴端扭矩；层绕会改变半径和速度。锚、链/绳质量、下放长度、需要的收放速度、额外减速、刹车/防溜、收纳到位、最大放绳、卡滞停止和手动解困均未验证。不能给出已满足牵引力、功率或续航的结论。
