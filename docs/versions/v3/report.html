肋骨槽与纵梁调整

水平接收槽高度 = MATERIAL_THICKNESS + FIT_CLEARANCE = 3.00 + 0.12 = 3.12 mm。槽以横板中心高度定位，上下各留0.06 mm名义间隙；CUTTING_KERF=0.15仅为切割工艺参考，尚未用于CAM。支承槽通常位于两舷肋骨内侧，升降机井处允许局部缺失/让位；槽后名义保留2 mm背壁。这是几何配合设计，不是全实体最小壁厚或强度认证。
