# V3 双连续横板独立复核

复核日期：2026-10-17。对象为当前 V3 源码、参数、场景数据和三个原生3dm。除本记录外，未修改模型、输入或生成脚本。

结论：当前默认参数下未发现阻止概念结构评审的几何问题。两块横板、接收槽及后纵梁避让在静态装配位置相容；尚不能据此判定两块刚性板能按某个顺序实际穿装。

## 包内生成与参数边界

构建和网页生成使用包内相对路径；three.js、OrbitControls和场景数据内嵌于HTML。构建不需要修改V2目录。原生几何仍基于包内母面源码及参数生成，V2输入3dm用于保护对照。

已复核两项便携修复：`requirements.txt` 增列 `manifold3d>=3.5`，满足布尔验证脚本的显式引擎依赖；验证脚本移除固定 `R.parents[1]`，改为遍历祖先可选核查包外原件，避免直接在盘符根目录解压时的祖先索引越界。源码另已显式要求三份指定包内备份存在、各有唯一登记SHA并匹配。本轮检查了现有包内三份备份的SHA，未删除备份做缺失注入测试。

当前横板厚度、门口对齐高度、800 mm总长、3 mm材料、Z76甲板底及Z32参考高度均有构建约束。上板起点、横板轮廓、定位孔、背壁及纵梁避让均为D模型设计，不能视为实舰内部尺寸。更改参数后应重新生成、核验预留及板件干涉。

本轮未另建目录执行全套解压重建，也未独立重跑浏览器交互；应结合相应交付验证记录评估完整包的可重复生成。

## 未验证事项

原生Rhino桌面操作、Join/裸边/水密、两板真实穿装路径、木纹/切割余量/强度和实物干拼均为 **NOT_CHECKED**。当前封闭板件无静态交叠，不等于装配运动可行或制造工艺已通过。

蒙皮仍为零厚度参考面，1.25 mm肋骨内缩尚未完成与3 mm实物蒙皮的协调。后纵梁3.94 mm窄腹、2 mm名义槽背壁和长上板均需后续实物与强度评审。此版保持概念审阅状态，不是切割放行包。
