# 076-800 展示功能模型：总体方案修订稿

来源：用户于2026-10-19在本次聊天提供。以下按原稿整理并合并部分列表，保留条款与数值；非逐字转录。网页和整理本均不新增已冻结的几何或硬件参数。

## 1. 项目目标与优先级

制作一艘成品总长不超过 800 mm、以约 3 mm 木板骨架为主、内部可安装设备的 076 外观参考模型。

当前阶段主要用于：

- 放在展示底座上，离水向评委演示。
- 展示两侧升降机、真实收放锚和机库灯光。
- 使用手机分别控制，也能执行一键演示。
- 在手机上查看实际电源数据。
- 保留后续推进、舵系和其他功能的扩展条件。

设计优先级为：外观协调 → 演示可靠 → 便于维修 → 结构可制作 → 后续扩展。

整船下水与航行仍属于后续验证阶段。当前离水演示成功，不能等同于已经通过水密、浮态或航行检查。

## 2. 已确定的核心需求

| 项目 | 已确定内容 |
|---|---|
| 总长 | 全部部件的纵向包络不超过 800 mm |
| 主体结构 | 木质骨架、蒙皮，内部保持可用空间 |
| 升降机驱动 | 电动、平稳、隐藏；允许推杆或丝杆方案 |
| 升降载荷 | 约 15 mm 长、3 g 的塑料飞机模型 |
| 飞机运输 | 不要求飞机进入机库 |
| 右舷升降机 | 优先完成真实升降展示 |
| 左舷升降机 | 做升降与内部展示 |
| 入口形式 | 外舷壁门框＋内部机库门框，中间形成短通道 |
| 隐藏机构 | 允许局部内墙加厚、设置设备夹层 |
| 机库内景 | 灯光、顶梁、内墙及少量飞机，形成局部立体场景 |
| 操作方式 | 手机程序控制，各功能独立操作，并支持一键演示 |
| 供电 | 船内独立电池 |
| 续航目标 | 约 1 小时，灯光持续工作、机构间歇动作 |
| 锚机 | 锚能够真实下放、收回并停在收纳位置 |
| 数据显示 | 电源状态及运行数据可视化 |
| 扩展要求 | 模块可更换，预留接口、安装位置和走线空间 |

载荷以最后确认的 3 g 塑料飞机为准。前面讨论过的“带电机、电池的功能飞机”，不再作为当前升降机的设计载荷。

## 3. 当前模型哪些保留，哪些重做

建议保留：

- 现有 Rhino 船体母型和版本记录。
- 已建立的整体坐标与 800 mm 包络。
- 已有的部件分组、资料分级和检查记录。
- 可拆甲板、机库检修的设计方向。
- 平台下位与内部转移地板齐平的关系。
- 新网页已经改善的视角保存、问题提示和零件证据卡。

优先重做：

1. 两处升降机的外露导轨与支架。
2. 升降机附近的外舷壁开口和双层门框。
3. 被开口切改的局部肋骨、甲板承托和纵向连接。
4. 隐藏驱动、导向滑座和连接臂的安装关系。
5. 机库内景、灯线与可拆结构之间的接口。
6. 艏部锚机、锚链导向及检修空间。

当前不建议全面重建船体。先解决局部结构与机构冲突，再判断外形是否需要进一步调整。

## 4. 升降机：外观、运动和承力一起设计

### 4.1 推荐结构

固定承力框架 → 隐藏导向滑座 → 平台连接臂 → 升降平台。

执行器驱动滑座或平台组件，门框和内景独立安装。

必须明确各部分职责：

- 固定框架：把载荷传给相邻肋骨和纵梁。
- 导向件：限制倾斜、扭转与横向摆动。
- 执行器：提供升降动力。
- 门框与内景：形成外观和空间层次。

不能默认由细小装饰门框、薄蒙皮或单根伸缩杆承担全部载荷。

### 4.2 隐藏方式

优先研究将导向和驱动集中在入口两侧的局部夹层，连接臂避开主要观察方向。

同时保留：安装和调整空间、紧固件的工具操作空间、线束活动余量、向上或向内取出整个机构的路径。

隐藏后仍要能维修。不能为了看不到机构，把它永久封在船壳里。

### 4.3 平台尺寸与行程

旧版的 52×43 mm 平台、32 mm 行程只能作为比较基线，尚未冻结。

下一步应根据整船外观比例、上位与飞行甲板的衔接、下位与内景地板的衔接、执行器实际安装尺寸、新门框与平台的运动干涉，共同决定最终尺寸。

3 g 是飞机重量，选驱动还必须计入平台、连接臂、滑块自重和摩擦。

## 5. 双层入口与局部机库内景

### 5.1 入口形式

外舷壁门框 → 有顶面和侧壁的短通道 → 内机库门框 → 局部机库场景。

外观应表现倒角矩形轮廓、可辨认但不过厚的壁厚、完整的门楣和两侧门柱、内外两层之间的纵深和阴影，以及平台、门槛与内部地板的协调关系。

倒角大小和具体轮廓属于模型设计参数，不能宣称是已经量测确认的 076 实舰结构。

### 5.2 必须解决的干涉

现有平台运动范围覆盖了部分舷侧位置，不能直接在原大缺口上加门楣。

需要重新安排门框、平台内缘及连接臂，检查从最低到最高位置的完整运动范围。

### 5.3 内景

飞机无需进入机库，因此可以采用局部立体内景，保留更多承力材料和设备空间。

建议包括少量顶梁与灯具、有层次的内墙和地板、少量飞机或地面设备、柔和照明和必要遮光、可拆内衬及插拔式照明接头。

固定外门框与可拆机库之间应有明确的拆卸边界，避免加装内景后破坏原有检修功能。

## 6. 骨架与制作要求

两处升降机周围优先形成固定的局部承力框架：

- 开口前后连接到可靠肋框。
- 上下设置适当横向连接。
- 保留纵向连续传力路径。
- 导向支座固定在结构节点上。
- 必要时局部采用叠合木板、实木条或金属安装板。

约 3 mm 木板是主体材料，不要求所有机械安装件都只能使用单层 3 mm 板。

还应检查整块甲板取下后骨架能否保持形状；开孔和插槽是否留下过细连接；蒙皮厚度是否与肋骨退让量一致；木板厚度误差、涂层厚度和加工误差是否进入配合设计；装配顺序是否实际可执行。

建议先制作一个单侧升降机样段，验证门框、骨架、导向、驱动和涂装间隙，再完成全船。

## 7. 锚机系统

已确定真实收放锚。需要预留隐藏驱动与收放机构、锚链／锚索导向和收纳空间、收锚到位检测、最大下放限制、卡链时停止及手动解困条件、可拆检修盖、锚与展示底座之间的净空。

收回后应停在与船体外观协调的位置，避免持续拉紧、撞击或悬挂晃动。

暂定建议，尚待最终确认：首版做单侧真实收放，锚下放后悬空停留。另一侧保留外观与改装空间。下放长度由底座净空确定。

## 8. 手机控制与可扩展电控

手机控制已确定；具体采用本地网页还是安装式 App，尚未最终冻结。

目前推荐：手机本地控制页面 ↔ ESP 类控制板 → 各功能驱动模块；电源检测和到位传感器 → 控制板 → 手机状态显示。

首版控制功能：左右升降机独立操作、锚机收放、机库灯光开关与调光、一键演示、停止演示、连接／故障／到位状态显示。

一键演示顺序由船内控制板执行。断联后停止后续动作，重新连接不自动恢复运动；平台停止后防止自行下落，需要机械方案配合。

扩展方式：

- 主控、驱动、供电检测采用可维护的模块组织。
- 设置可拆电控托盘和可拔插线束。
- 保留少量备用接口与走线空间。
- 推进、舵机及其他未来功能按各自负载增加驱动。
- 不为尚未确定的功能提前装满模块。

ESP 负责控制信号，电机由匹配的驱动器供电。

## 9. 电源与手机数据可视化

续航目标定义为：灯光与控制系统持续工作，升降机和锚机间歇演示，总时长约 1 小时。

电池型号、串数、容量和尺寸尚未确定，需要根据实际执行器和演示流程核算。

| 数据 | 要求 |
|---|---|
| 电池电压 | 实测值及趋势 |
| 总电流 | 实测值及短时变化 |
| 实时功率 | 根据电压、电流计算 |
| 剩余电量 | 使用匹配电池的估算方案，标明估算性质 |
| 运行时间 | 记录本次演示时长 |
| 已用电量／能量 | 根据采样累计 |
| 预计剩余时间 | 后期依据实际负载加入 |

必须区分：已发送命令与实际执行状态、估算位置与传感器确认到位、电量估算与实测电压、实时数据与断连前的最后数据。

电控体积应按板件＋插头＋线缆弯曲＋固定件＋拆装空间一起规划。

## 10. 美术与演示风格

统一目标是：远看像完整舰船，近看有可信的入口和机库细节，动作时能看清功能。

重点调整：隐藏突兀外露导杆架；舰岛、甲板、舷侧与平台材质和颜色协调；处理长条舷侧构件支撑、端部和开口收口；入口通过壁厚、纵深和照明建立层次；内景适量且不遮挡维修；工程模式保留分色、成品展示模式体现涂装；手机界面简洁、主要按钮易操作、数据页与操作页分开。

参考图片可以用于美术和制作方法借鉴，但不同舰种模型中的结构不能直接作为 076 的真实依据。

## 11. 下一阶段的交付与验收

下一阶段先完成布局与样段验证，随后再出完整切割件。

建议交付：

1. 两处升降机区域的剖面与结构布置。
2. 双层入口、内景和机构之间的空间关系。
3. 锚机及锚链路径。
4. 电控托盘、电池位置和走线规划。
5. 候选执行器的尺寸与安装检查。
6. 单侧升降机样段及锚机试验记录。
7. 手机控制流程和遥测数据定义。
8. 更新后的未验证事项清单。

主要验收条件：完整行程不刮碰、不明显倾斜、到位整齐；重复动作后不明显松动卡滞；锚受控收放且卡住可处理；内景和机构可分别检修；手机状态有真实数据依据；按约定流程实测达到一小时续航；制造、强度、水密和航行检查分别记录。

当前仍待确定：执行器、最终平台尺寸与行程、电池方案、手机接入方式、锚机侧数和下放终点。其余总体方向可以作为后续设计依据。
