# 076-800 V9 升降机位置与图片证据审查

审查时间：2026-10-18。范围：用户实拍图6/7、五张模型截图、四个第三方CAD/CGI文件及两个重复截图，配合公开原始报道/分析，核对升降机大致布置，并为模型竖向导轨、无蒙皮上部过渡和完整甲板提供边界。此审查没有修改原生模型或网页。

## 结论与可执行边界

现有模型“右舷两岛之间、左舷近艉”的布置方向与公开资料一致，没有足够证据要求仅凭图6把两个升降机改到另一组精确坐标。**位置关系可保留，精确毫米坐标仍属模型假设。** 这不是已完成摄影测量或真实舰比例校准的结论。

实拍图6是左舷艉斜视：左舷后部的平台、平台下方两端的竖向构件和局部开口可见。可据此增加模型的竖向导向外观，并检查平台与船体的上下连接。右舷在远侧，受甲板和舰岛遮挡，不能从这张图独立精确核对右舷平台。图7与图6完全相同，不能作为第二视角。

完整飞行甲板的总体外观由官方资料支持；甲板可拆分块、固定边框、3mm板厚、上部过渡肋骨/纵材和新增导轨的尺寸应按800mm模型的装配、运动与维修需要确定。用户模型截图是“当前模型问题”的证据，第三方CGI只作外观意向参考。两者均不证明真实076内部结构。

## 证据分级

|等级|本审查含义|限制|
|---|---|---|
|A|官方明确陈述|只覆盖原文确实说出的事实|
|B|不同机构原始报道或分析交叉一致|转载同一张照片、同作者前后文章不算新增独立来源|
|C|公开照片定性判读或估测|非校准量测；不承诺毫米级误差|
|D|模型设计假设或模型参数|数值可检验，但不自动转为真实舰事实|
|Unknown|本次资料不足|保留为空或明确未知|

具体分级以[claims.json](claims.json)逐条记录为准。独立互证充分的是“两舷各一”这一粗布置；精确纵向的文字描述主要来自Naval News，不能把这一点夸大成两家独立来源均给出了精确位置。
